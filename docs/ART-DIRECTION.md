# 持续适用的美术偏好

用户明确要求：不要乱画细条。从第一部到后续作品都要避免用细条、碎线和格栅堆砌细节。

优先看完整轮廓、大形体、清楚的明暗色块和留白。细节要服务于物体结构、材质或玩法，并在普通游玩距离下可读。地面用连续铺装面和合理的材质关系组织，不加无意义的长描边或分割网。建筑门窗用少量明确的真实构件组织，减少互相叠加的细框和装饰线。远景细小构件应平滑淡出。

用户指出的具体问题：沿街人行道上的深色装饰细线；东方明珠入口的重叠门窗格与屋顶黑色放射线。这些例子用于识别同类问题，不能只擦掉圈中的局部而保留相同做法。

验收时看实际引擎截图里的整体秩序、近景结构与游玩视距，不能把细节数量当作精细度，也不能用功能测试通过代替画面判断。

三条最高准则保持原文：Gameplay 优先；视觉、操作、剧情一致；PS3 等级视觉方向。
