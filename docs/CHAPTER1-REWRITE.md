# 第一章整体重排：先把一顿生日饭讲完整

2026-10-23，回应0.6.0实玩反馈：主线不足十分钟、对白像任务摘要、蛋糕到生日再到打架缺因果。此方案替代“竞速→送货→播五句话→开战”的旧节奏。地标与天赋系统保留，不以新增支线替代主线的完整叙事。

## 参考做法与本作取舍

[《如龙》制作组20周年访谈](https://blog.playstation.com/2025/12/19/like-a-dragon-20th-anniversary-interview/)强调先确定戏剧主题、再设计与人物和主题相合的城市活动；借鉴生活内容让人物成立，不复制它的桥段。[《神秘海域4》官方试玩介绍](https://blog.playstation.com/2016/04/04/uncharted-4-gameplay-video-hands-on-report/)介绍较自由的路径与有控制的叙事节奏并存；借鉴移动/探索的自由，以及关键事件前后交代清楚，不把每句话都变成停下看电影。以下具体剧情、时长目标和系统为本作自定。

## 第一章的情绪与因果

这一章讲豚师答应陪八个儿子认真过生日，却发现攀哥为保护一个受伤、想退出比赛的年轻人，正在独自承受压力。前半段让玩家喜欢这次家庭出游，后半段才使“攀哥没回来”成为具体损失。Carry不在本章正面登场，他的人有明确目标：逼攀哥说出SN在哪，而非随机打生日宴。攀哥离席是因为来人已到后勤门，想把对方带离家人；豚师出门是亲眼发现他在交涉。对方堵出口并推搡工作人员，豚师先让家人与普通人撤，冲突才转成玩家战斗。

## 连续流程

|---|---|---|
| 抵沪碰面 | 八子依次下车；和老朋友谈安排，孩子发起天桥竞速 | 大家为何来、生日在哪里、豚师答应看完节目 |
| 一家人的上海 | 天桥可选路线竞速；上海中心实际登高、观景镜与合照；三栋楼可选支线 | 八子分别关注路、动作、音乐与食物；不是八个相同任务NPC |
| 蛋糕和电话 | 自由驾驶运蛋糕，车内完整往返对话；攀哥电话先让炫神别带陌生人进场，遇追问却回避 | 攀哥有事瞒着大家，但玩家尚不知道全部，不提前把谜底一次说完 |
| 到场与排练 | 真实进门、象象接待；孩子请爸爸帮排一段戏，纸板道具提供非致命近战、破防、闪避的可玩排练，低评价照样继续 | 朋友与家人的关系、孩子怎样理解爸爸；轻松活动也为后面的真实保护作对照 |
| 生日饭 | 众人说完一段有来有回的话，孩子的节目开场；攀哥接到催促，明确说去后勤门谈事，拒绝把对方领进来 | 电话与离席接上；大家知道他去哪里，不靠“手机莫名其妙落桌上”催玩家追人 |
| 去门外看看 | 玩家亲自从正门走到后勤院落，看到攀哥、来人和工作人员；镜头中的交涉讲清SN伤着、不愿再打、Carry的人要求交人 | 人物各自想要什么，为何意见无法一致，豚师不再是毫无理由出拳 |
| 交涉破裂与撤离 | 攀哥为让对方离开宴会而跟车走；留下的人堵住工作人员，推搡发生；战斗接同一位置、同一出口 | 对方升级冲突；豚师目标是护送普通人而非追车，关门与接应车都有叙事原因 |
| 铁闸拦路 | 工作人员安全后，沈铁川作为独立章底Boss登场，专属模型、姓名演出、两阶段连拳/扫踢/冲肩，失败直重试 | 门口下令者为自己的决定承担结果；章底有完整对决而非杂兵清完就结束 |
| 蛋糕还留着 | 确认人都安全，孩子问攀哥为什么没回来；炫神说明车向南京路去；小朋友要求豚师讲清安排，几人分工后才结束 | 本章完成了家人安全，留下营救攀哥的明确下一章目标；不是一盘散沙地突然MISSION COMPLETE |

## 对白标准

每场戏必须有人要说服、回避、安慰或试探另一个具体的人。对方回应上句话，不能轮流各念一句任务摘要。豚师的自称和听歌的史书腔是偶尔的性格笑点，不能每句都像标语；小朋友可以直接问关键问题，攀哥的关照里带回避，炫神先说实际办法，孩子有不同注意力与误解。保留普通口语中的停顿、追问和没立刻说完的意思，避免人人简短工整对仗。

关键对白默认完整配音，可C切自动/手动；E/Enter推进一句，Tab明确跳过整场，Esc暂停。全跳过也按相同完成事件交接，J日志的剧情回顾只记录玩家已到达的事实，不透未来章节。移动时对话不夺走驾驶/行走控制，关键交涉才使用人物与机位调度。

## 篇幅与验收

目标是正常观看与操作的主线约30–40分钟，选择三条地标支线后另有可玩内容。此为结构目标，不把语音总长或自动测试时间当实际首玩时长，不宣称未经人工首玩计时已经达标。不能靠更远的无聊跑腿、强制全支线、重复几波敌人或拖长镜头凑数。

验收先看连续游玩：不了解设计文档的人在开战前，应能说清“攀哥帮了谁、对方要什么、他为何离席、为什么工作人员有危险、豚师现在要保护谁”。生日排练与冲突分段存档，失败不重播一下午。T天赋、J支线与旧档继续兼容；原版豚师和既定画风不变。Windows Release必须反映最终代码，不拿0.6.0通过记录替改动背书。
