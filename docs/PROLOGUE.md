# 序章《一个都不少》 / 0.5.0

本轮依据用户确定的章节大纲和角色图，实现长沙开场。大纲见 STORY-OUTLINE.md；第一部结尾依据 TUNSHI1-STORY.md 的证据边界。豚师本人一胎生下八个儿子，小朋友负责家庭安排。没有将机器展示或商业调查硬塞进开头。

正常入口为 boot.tscn，再进入 prologue.tscn。标题有开始/继续序章、陆家嘴自由漫游与退出。漫游的战斗、车辆、M地图、旧档保留；漫游暂停按T返回序章标题。第一章没有用旧陆家嘴样板冒充成品。

## 连续可玩内容

医院中，八只独立、带编号的婴儿篮和三位老朋友、小朋友实际在场。豚师可走动、与朋友闲聊，走近婴儿篮看到八子并与小朋友商量出院。随后亲自将黄色小车从接人处开至蓝色车位，停稳并安全下车，抱起可见的行李，送到蓝色全家车。小车不承担十人乘坐，炫神已安排大车；大车是剧情接送车辆，不是另一个可驾驶车型。

合照阶段会把八只婴儿篮、四位大人和豚师安排到真实位置，使用专门机位。对白结束后进入数年后的家中：八张小床、八个长大的儿子、他们的积木上海、音箱和点心均可见。三组家庭对话分别表现分角色、音乐与吃饭、清点与关心爸爸，完成后才接到攀哥的电话。听歌和炫神是电话参与者，不生成在场模型。最后答应看完整场小戏，收好合照，序章完成。

出生、出院、停车、装车、合照、家庭对话、邀请和完成均有检查点。没有把八次重复取物作为主要玩法。序章是短篇可玩开发版本；八子成长目前由场景切换与简短旁白表示，没有完整多年育儿模拟、配音或预渲染影片。

## 角色与美术

原版豚师使用 StreetActor 和 assets/original_dolphin.json，SHA256 保持 7333d7666dd647f9fd858b7001bce2821705b9f6134425b0f399faacc451a08e。未改英雄的头脸、嘴、眼睛、腹部、鳍或比例。

StoryCast 对复制后的原始数据制作粉色小朋友与八子。小朋友有蝴蝶结和小王冠；儿子采用白衫、红领巾、深蓝裤和不同颜色的1–8徽章。听歌为紫衣、眼镜和黄耳机；攀哥为绿外套与浅色内衫；炫神为橙色闪电衣与刺头。牢东杰的新版草帽、红马甲、眼罩造型留作后续出场，不改第一部历史记载。本轮角色图只用于造型参考，不将用户上传图或原生截图上传仓库。

两个新场景沿用既有 cel shader、天空与光照，使用大色块和实用构件。静态几何在材质转换前合批，人物关节保留。医院墙、婴儿篮、人物、家具和院子边界有实体碰撞；情节人物没有战斗AI，原漫游普通行人的受击机制保持。没有引入地面共面网格；两块停车色面抬高至独立高度。

## 存档和恢复

正常序章：user://shanghai-prologue-v1.json；自动序章验证：user://prologue-test.json。二者与原来的shanghai-toon-save.json / toon-test-save.json完全分开。开标题和切进漫游不会凭空写入/覆盖尚未开始的序章。

保存阶段与已完成家庭对话，不保存任意坐标。搬运中读档会把行李放回门口，保留已停好的小车，避免拿到一半软锁。R请炫神将车摆正和修好，但不会跳过停车目标。车辆撞实墙仍使用原相对速度损伤规则，车与车内豚师都会扣血；致命伤返回可恢复状态。
