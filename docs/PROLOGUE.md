# 序章《一个都不少》 / 0.5.2

本轮依据用户确定的章节大纲和角色图，实现长沙开场。大纲见 STORY-OUTLINE.md；第一部结尾依据 TUNSHI1-STORY.md 的证据边界。豚师本人一胎生下八个儿子，小朋友负责家庭安排。没有将机器展示或商业调查硬塞进开头。

正常入口为 boot.tscn，再进入 prologue.tscn。标题有开始/继续序章、陆家嘴自由漫游与退出。漫游的战斗、车辆、M地图、旧档保留；漫游暂停按T返回序章标题。第一章没有用旧陆家嘴样板冒充成品。

## 连续可玩内容

医院中，八只独立、带编号的婴儿篮和三位老朋友、小朋友实际在场。豚师可走动、与朋友闲聊，走近婴儿篮看到八子并与小朋友商量出院。随后亲自将黄色小车从接人处开至蓝色车位，停稳并安全下车，抱起可见的行李，送到蓝色全家车。小车不承担十人乘坐，炫神已安排大车；大车是剧情接送车辆，不是另一个可驾驶车型。

合照阶段会把八只婴儿篮、四位大人和豚师安排到真实位置，使用专门机位。对白结束后进入数年后的家中：八张小床、八个长大的儿子、他们的积木上海、音箱和点心均可见。三组家庭对话分别表现分角色、音乐与吃饭、清点与关心爸爸，完成后才接到攀哥的电话。听歌和炫神是电话参与者，不生成在场模型。最后答应看完整场小戏，收好合照，序章完成。

出生、出院、停车、装车、合照、家庭对话、邀请和完成均有检查点。没有把八次重复取物作为主要玩法。序章是短篇可玩开发版本；八子成长采用合照回看、卧室内幼年姿态与长大后家庭互动的连续镜头，带54段离线中文TTS。没有完整多年育儿模拟或预渲染影片。

## 角色与美术

原版豚师使用 StreetActor 和 assets/original_dolphin.json，SHA256 保持 7333d7666dd647f9fd858b7001bce2821705b9f6134425b0f399faacc451a08e。未改英雄的头脸、嘴、眼睛、腹部、鳍或比例。

StoryCast 对复制后的原始数据制作粉色小朋友与八子。小朋友有蝴蝶结和小王冠；儿子采用白衫、红领巾、深蓝裤和不同颜色的1–8徽章。听歌为紫衣、眼镜和黄耳机；攀哥为绿外套与浅色内衫；炫神为橙色闪电衣与刺头。牢东杰的新版草帽、红马甲、眼罩造型留作后续出场，不改第一部历史记载。本轮角色图只用于造型参考，不将用户上传图或原生截图上传仓库。

两个新场景沿用既有 cel shader、天空与光照，使用大色块和实用构件。静态几何在材质转换前合批，人物关节保留。医院墙、婴儿篮、人物、家具和院子边界有实体碰撞；情节人物没有战斗AI，原漫游普通行人的受击机制保持。没有引入地面共面网格；两块停车色面抬高至独立高度。

保存阶段与已完成家庭对话，不保存任意坐标。搬运中读档会把行李放回门口，保留已停好的小车，避免拿到一半软锁。R请炫神将车摆正和修好，但不会跳过停车目标。车辆撞实墙仍使用原相对速度损伤规则，车与车内豚师都会扣血；致命伤返回可恢复状态。

## 0.5.1 室内、导航与演出

医院和家中均有实际天花板与封闭墙体。医院玻璃门有传感器、滑动门扇及匹配碰撞，走近打开、离开安全范围关闭；玄关双扇木门沿门轴打开。家中包括玄关、客厅和带滑门的独立儿童睡眠区，添置接待台、柜子、生日板、植物与实际照明。新增独立局部照明着色器，保留陆家嘴原有光照，防止点光源重复叠加卡通阴影底色导致过曝。

导航依据剧情状态指向婴儿篮、小朋友、自动门、黄车、蓝车位、行李、装车处、合照位置、三组八子对话、电话和玄关。显示实际距离，目标不在画面内时保留边缘箭头；相邻标签自动错开。室内外的目标先通过门口，不要求对着墙找车或行李。E仍需满足真实距离和墙体遮挡检查。

assets/dialogue/prologue.json是字幕和配音的同一来源，assets/voice包含54段中文TTS与音色/时长/哈希清单。使用通用合成音色，没有真人克隆。工具generate_voice.py基于edge-tts 7.3.1（https://github.com/rany2/edge-tts），仅制作时联网；游玩无网络请求、无额外语音包。V开关配音，C开关自动对白，跳句停止旧音频，Esc暂停/恢复音频和计时，读档与切场停止音频。首批全部MP3通过ffmpeg解码与非静音检查。

PrologueDirector管理医院起身、指向门和车辆的镜头、集合淡入、挥手合照/快门、八子成长与全家出发。合照仅保留在内存中供蒙太奇回看，不写入仓库或发布截图。镜头留在实体屋顶之下；蒙太奇按实际TTS长度安排时间。E/Enter跳过时仍应用完整的最终状态，中途暂停会冻结镜头和声音，中途保存不会提交半完成的成长阶段。

原30项检查继续保留，新增21项覆盖完整语音包、AudioStreamPlayer实际播放、暂停/跳句/自动继续、物理天花板、自动门开关与真实穿门、门口导航和车位导航、合照演员/镜头、成长蒙太奇与检查点保护、家庭目标。Windows版本还需在CI跑原107项回归和51项序章，并解压ZIP直接运行EXE再次验证51项。新版本Windows显卡实机未在本环境验收。

## 0.5.2 老朋友面部

StoryFace单独构建听歌、攀哥、炫神的人类面部，保留角色图的发型、衣服与配件辨识。头部有不同的下颌比例，曲面眼睛有眼白/虹膜/瞳孔和眼睑，眉形、鼻梁/鼻尖与唇形完整。听歌改为适配眼睛的镜框与连续耳机头梁；攀哥宽下颌、厚眉和侧分头；炫神收窄下颌并保留上扬眉与刺头。小五官取消身体级的粗描边和投射阴影，避免鼻部黑块、眼镜阴影碎线。

眼睛按错开的时序眨动，闭眼使用完整眼睑线，不残留白线。说话用多种开口/宽窄口型切换，按对白时长收口；这是程序化说话动作，不是逐音素唇形匹配。暂停菜单同时冻结人物动作、眨眼和口型。原版豚师及家族模型不受影响。近景、侧面与正常游玩距离在实际医院环境复查，验证聚焦本轮面部变化，完整回归由Windows发布CI负责。
