《豚师2·上海风云》0.5.4：承接第一部结局的开场演出。

下载 `Dolphin2-Shanghai-Windows-v0.5.4.zip`，完整解压后双击 `Start.cmd` 或 `Dolphin2.exe`，无需安装Godot、Python或语音包。

从长沙橘子洲问天台的黎明接起：蓝衣朋友重新来到豚师身边，豚师先宣布“海豚帮解散”，再宣布“海豚蒂国成立”。沿用第一部确定的正式结局，不改写战败对手的去向。随后回到长沙家中，小朋友把困告的元首喊起来准备八子计划，淡入现有医院开场。

演出包含原创3D晨光江景、家中场景、角色归队/起身、分镜、淡入淡出、环境声和轻音乐。新增11段中文TTS，与字幕统一，总计65段语音离线随包播放。保持原版豚师模型、明快卡通画风与三位老朋友的圆润眼型。

新游戏自动播放。E/Enter或点击可跳过，Esc暂停画面与声音，V开关配音。标题“重看开场”可独立回看，不覆盖进度；旧序章检查点继续兼容，未完成开场的检查点可安全重新播放。原来的医院、挪车、合照、八子成长、家庭互动及陆家嘴漫游保留。

本版仍是序章与漫游，第一章未制作。第一部第五章最终源码未恢复，开场场景依据用户确定的结局重新演绎，不宣称恢复原片。Windows CI负责独立PCK和解压EXE运行验证；本版没有Windows GPU实机结论。默认不输出截图，新增捕获不入库或Release。
