《豚师2·上海风云》0.5.3：三位老朋友改用更亲切的卡通眼睛。

下载 `Dolphin2-Shanghai-Windows-v0.5.3.zip`，完整解压后双击 `Start.cmd` 或 `Dolphin2.exe`，无需另装Godot、Python或语音包。

听歌、攀哥、炫神的眼睛改为圆润椭圆轮廓，去掉尖眼角和上挑斜度，缩小眼白占比、放大虹膜与瞳孔，加入柔和高光。眉毛更短、更柔和，听歌镜框的纵向空间适配新眼型。眼睛各层贴合头部曲面，转头时保持完整，眨眼仍使用闭合眼睑。

三人的脸型、鼻嘴、发型、服装配件及原版豚师/家族模型保留，剧情、54段离线TTS、存档、操作与陆家嘴漫游保持兼容。

本轮只针对眼睛做内部图形复查，发布前由Windows CI完成PCK和解压EXE运行验证。默认不输出截图；新增截图、视频和图集不入库或Release。本版未做Windows GPU硬件验收，第一章仍未制作。
