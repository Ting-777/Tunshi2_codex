《豚师2·上海风云》0.5.0 序章开发版：一个都不少。

下载 `Dolphin2-Shanghai-Windows-v0.5.0.zip`，完整解压后双击 `Start.cmd` 或 `Dolphin2.exe`。无需安装 Godot 或 Python；EXE 和 PCK 必须放在同一文件夹。Windows 64 位，显卡需支持 OpenGL 3.3。

序章从长沙医院开始：豚师本人完成八子计划，亲自挪车、搬行李，与老朋友拍第一张合照。几年以后，在家陪八兄弟准备小戏，再接到上海的邀约。听歌、攀哥、炫神与八子按照用户角色图制作；豚师保留第一部原始几何。

WASD 移动/驾驶，鼠标转视角，E 互动/上下车，空格跳跃/手刹，R 请炫神挪车，F5 保存，F9 读取序章检查点，Esc 菜单。对话按 E、Enter 或点击继续。标题可单独进入原有陆家嘴自由漫游。

序章使用独立存档，不覆盖陆家嘴旧档；第一章尚未制作。本包属于可玩开发版本。Windows 自动检查为 CI 无显示运行，不等于所有 Windows 显卡、手柄或性能均已验收。实际原生截图仅在开发对话展示，不上传仓库或 Release。
