《豚师2·上海风云》0.5.2：听歌、攀哥、炫神面部重制。

下载 `Dolphin2-Shanghai-Windows-v0.5.2.zip`，完整解压后双击 `Start.cmd` 或 `Dolphin2.exe`。无需安装Godot、Python或语音包。

三位老朋友新增有眼白、虹膜和眼睑的眼睛，按角色区分眉形、脸型和下颌，补齐立体鼻部及自然唇线，替换原来的豆豆眼与椭圆嘴。听歌保留黄耳机和眼镜，攀哥保留绿外套与侧分头，炫神保留橙色闪电衣和刺头。简笔画用于人物标志参考，游戏角色按既定卡通画风完善。

加入错时眨眼和多种说话口型，配音结束后收口，Esc暂停同步冻结人物表情和动作。小五官使用克制的描边与阴影，避免眼镜/鼻部产生突兀黑块。

原版豚师几何、小朋友、八子、序章剧情和检查点继续保留，54段离线中文TTS及原陆家嘴漫游可用。操作不变：E互动，V配音开关，C自动对白，Esc暂停。
