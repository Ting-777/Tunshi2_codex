《豚师2·上海风云》0.6.0：第一章《八个，一个都不少》。

下载 `Dolphin2-Shanghai-Windows-v0.6.0.zip`，完整解压后双击 `Start.cmd` 或 `Dolphin2.exe`，无需安装Godot、Python或语音包。标题选择“第一章 · 八个，一个都不少”即可进入，完成序章后也可从玄关前往上海。已有序章与漫游存档保持独立。

Gameplay 优先：和老三从南坡道跑上环形天桥，东/西半圈任选，北侧下桥。实际竞速对手、计时和可重跑的最好成绩；慢慢完成也能继续。随后在中心绿地取生日蛋糕，开有十个座位的全家车前往滨江，路线自选。碰撞会伤人、损车和损坏蛋糕，急转也影响完整度；低分仍能开饭，坏车可请炫神接应。

滨江生日饭被打断后，亲手保护工作人员从真实出口撤到接应车。追击者会攻击工作人员，守备打手要重击/踢击破防或绕侧，冲撞手有地面预警与失手硬直。关后勤门能挡住实际增援，车辆也能堵门，门下有人/车时不会强行关闭。失败只重试这场撤离，保留竞速和送货进度。

新增完整屋顶、自动门、灯光、家具和生日舞台的江畔会客厅，以及有实际通路的后勤庭院。八子出现在抵沪、竞速、乘车、聚餐、撤离和章末。增加37段中文TTS，总计102段随包离线播放。保留原版豚师几何、明快都市卡通风格、圆润人类眼型、第一部结局衔接开场、序章与自由漫游。

WASD移动/驾驶，鼠标视角，E互动/上下车，左键连击、R重击、F踢击、G/右键闪避、B格挡、Q热血、1回复，M地图、Esc暂停、V配音、F5/F9保存/读取。演出E/Enter跳过。第一章暂停菜单可重玩本章、重试本场战斗或接应车辆。单独章节存档保存受伤、车损、门、敌我状态和破坏。

本版可完成至第一章结尾，第二章及后续尚未制作。Windows CI验证独立PCK与解压EXE；没有本版Windows GPU硬件验收结论。默认不输出截图，新增截图、视频和图集不上传仓库或Release。
