# 《豚师1》玩法知识与可继承经验

剧情对应 TUNSHI1-STORY.md；原始证据见 reference/tunshi1。第一部是网页 Three.js 游戏，本仓库是 Godot 原生续作，不可以把网页接口名称当作已移植功能。这里记录系统设计与行为约束，具体能力以当前 scripts 为准。

## 基本循环

自由步行、车辆上下车与驾驶、近战、热血、道具、可破坏家具/装修/部分建筑、掉落、钱与购买、室内外通路、地图、故事任务、检查点和自由探索。任务不应只有到达坐标：到场后需要观察、认车、潜行、操作设备、追逐拦截、拆结构、保护对象或做小游戏。第一部后期有多层室内、地下与街区连接，不依靠提示文字掩盖不通的门。

网页阶段的操作包括 WASD 移动驾驶、E 互动/上下车、F 拳击、Space 跳跃、X/左 Ctrl 蹲下、右键/G 闪避、Q 情境热血/持物动作、1 回复道具、M 地图。不同阶段 Q 的情境动作不能简单混成一个按钮逻辑；Godot 当前按键以 README 为准。步行常态就是跑动，不再新增无理由的冲刺负担。移动端横屏与多指输入必须互不抢占摇杆、视角和动作。

## 战斗、护送、追逐与破坏

敌人应有不同职责和可读动作：冲锋蓄力、守备正面格挡、重型牵制、掷瓶落点、呼叫增援。敌我双方的目标选择必须真实，护送/防守不能只围着玩家转。田博护送最终为 **四波**，主路与绕行共用完成记录，每波 3–4 人，其中两名优先攻击田博；终点广场战单独存在。田博 140 HP、承受基础伤害 50%、受击保护 1.2 秒，每清一波只回血一次，他能近身反击而不追远处敌人。此处数值属于第四章快照，不是续作照搬平衡要求。

四处记录/服务器有真实受击、损坏、失败和重试；曾出现 HP 永远 220 的假防守，已成为明确反例。放任敌人必须真的失败。近战要检查朝向、距离、高度、墙体遮挡，友军命中不能给玩家虚构连击或热血。敌人蓄力和冲锋应能打断或躲开，不能通过更高 HP 替代机制。

追逐应允许抄近路、提前拦截、开关改变路线、车辆堵停或控制碰撞，不能强制把路线跑完。追人的闸门开关要在玩家入场附近，留出可操作窗口，而不是放在终点闸门旁。守店有准备期，能用车、卷帘、雇人和加固改变入口；车撞店面会开出新入口。破坏要改变碰撞与通行，并保存损坏，不是只播粒子；不能随意拆外围楼板造成落空。

## 第四章设施、钱和长期效果

必经六种设施活动：**赛车、碰杯、台球、麻将、卡拉 OK、打砖块**。通过主线赞助回合自然穿插，完成有效回合即可，低分或输赢不应封死剧情；不要让玩家为赚钱或赢牌反复刷。八号台球厅在酒吧后巷到牌馆的路线承担认人的因果，不能再删成纯支线。

KTV 使用豚师三首原创歌 **《吹风》《蓝脑壳儿》《念豚师》**。挑战从自己的片段起点开始，32 音符；完整听歌与挑战分开。曾有点歌后从头播放并卡住的问题，需核实媒体时间轴、seek、缓冲、暂停、重开和付费回合的恢复，不能拿假音频代替。这里没有迁入歌曲录音文件；若续作需要使用，先恢复获准的原始音源，不能声称仓库已经包含。

湘城证券免费开户一次，之后 V 或顶部交易按钮可随时随地打开同一账户。打开面板时每秒更新报价，不能靠关开刷新；世界暂停但报价推进，后台隐藏暂停，不补离线时间。用个人钱包买卖，1/4、半仓、全仓按钱包购买力/该股持仓分别计算，向下取整、按下单时最新价格结算。

股价不是固定正弦或每次重开播种。使用保存的连续随机流、公共/个股冲击、波动聚集、不规则阶段和消息；这是游戏模拟，不接现实证券 API。剧情事件通过稳定 ID 原子改变估价和现价并去重保存，不能读档重复发放。五个股票为江湾饮品、星潮文娱、麓山数码、河东商贸、霓虹出行。具体接口和数值见原始 chapter4-stock-market.md。

天豚之靴必须 **剧情拿到后** 才生效，且只在第四章室外禁车步行段将 7.5 提到 12.75，即 1.7 倍，不能变成全游戏开场加速。长郡教师子弟之家的 **牛奶绵绵冰只能买一次**，当时售价 16、回复 45，永久减伤四分之一，不叠加。服装解锁和购买有真实外观与存档，王冠海豚不能提前在进优衣库前剧透。

时间随第四章剧情从下午到傍晚、夜间，剧情完结后每 10 分钟有效第四章游玩切换昼夜；暂停、UI、隐藏页和其他地区不计入。学校安静段和优衣库喘息不能被随处随机敌人破坏。

## 导航、恢复与跨系统一致性

蓝圈、地图、目标文本和实际可到达空间必须一致。距离按玩家实际位置计算，不能卡在固定 350m；地图无 undefined；屋顶台词在上楼前说。第三/四章“停车并下车”以 **目标区域内且步行** 成功，不绑定某辆停着的车或要求上下指定车。

对话涉及的现场模型保持到最后一句结束，电话人物不能凭字幕自动变成现场演员。鼠标 yaw 允许连续水平多圈，避免边缘截断和错误归一化；暂停/页面隐藏后清输入。血条针对玩家实际打中的对象，不被全场 AI 交战刷屏；顶部提示分层排版，移除无用的“豚师·摸鱼自由人”标签。

每次目标切换保存；部分调查、HP、敌人、装修损坏、小游戏下注与回合、物品/衣服、市场随机流和事件去重共同保存。普通刷新保留当前损伤，T/死亡重试从当前战斗恢复，不强迫重走整章。测试入口使用隔离槽，允许分别从第三章最后一步、河东刚到、接田博前、橘子洲落地、最终演出开始测试，但不能默认当成正常连续进度。**测试站不为旧档增加兼容负担；主站需要兼容且只在获授权范围实施。** 这一政策不能套成 Godot 可以随意删除用户存档。
