# 车辆、乘员与路人撞击 / 0.4.6

这是当前陆家嘴室外样板的玩法规则；保留直立车辆控制、原版豚师与既定都市卡通风格。

## 规则

车辆最大180 HP。实体碰撞使用移动前的速度减去对方碰撞速度，再投影到碰撞法线，得到接近速度；沿墙擦过的切向速度不会当成正撞。静态墙使用完整速度变化，两辆同型车各分担一半接近速度。车辆损伤为 `0.8 * max(delta_v - 2, 0)^1.6`，单次最多160；乘员伤害为 `0.55 * max(delta_v - 4, 0)^1.5`，单次最多100。这里的阈值、指数和上限都是游戏平衡参数。

一次碰撞按接触事件结算，不按每帧继续踩油门扣血。相同实体接触有24物理帧去重窗口，车辆被挡停后使用实际滑动速度，不能靠顶墙积出虚假高速。车况很差时动力减弱，HP为0时失去动力；刹车、惯性减速和安全下车仍保留。

车内伤害不受近战格挡或闪避免伤保护。撞击会显示车况数值/血条、豚师数值/血条、瞬时撞击反馈。存档保留车况和豚师HP。乘员伤势致命时，先解除驾驶关联、恢复站立碰撞，再按原有扣费规则回到街口，避免复位后仍被车辆拉走。

路人伤害按实际扫掠距离和相对接近速度计算；停车和原地重叠不构成撞击。撞击显示被撞对象的真实血条。存活者依据伤害倒地约3–8.5秒，之后仍需完成支撑/起身动作，头顶有实体时继续等待；严重撞击可以让HP归零，近处不会立即复活。倒地后的独立车辆受击区域跟随姿态，第二次真实经过仍能造成伤害；一次持续接触不会逐帧重复伤害。普通路人仍不掉敌人现金。

## 地面

原道路肩板与基础地面共面，多条道路的沥青板在交叉口重叠。现将六条道路、连续铺装、草地与滨江铺面统一到同一地面材质上，交叉口只有一个深度表面，保留原有连续地面碰撞。黄色边缘标记也在同一材质内绘制，交叉道路处断开，移除悬空条带及其错误阴影。远处铺装细纹随像素覆盖淡出，不增添装饰碎线。

自动检查验证实体撞击、正撞/擦碰/追尾/相向碰撞、持续接触、乘员伤害与死亡复位、路人倒地和二次撞击、保存读取，以及六条道路共享单一地面。还需结合原生截图和低机位移动镜头检查实际画面；headless不作为视觉验收。Windows真实硬件仍需另测。
