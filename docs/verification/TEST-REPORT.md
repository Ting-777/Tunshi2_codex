# 0.4.4 动作与行人反应验收 / 2026-10-21

本轮在原生 Godot 陆家嘴无任务样板上继续完善自由漫游。所有 Sites 未修改，原版豚师几何保持。三条最高准则原文：Gameplay 优先；视觉、操作、剧情一致；PS3 等级视觉方向。

## 行为与动作

人物受击踉跄与倒地方向根据实际冲击方向计算。倒地以可见模型的局部包围边界贴合当前地面，并收腿、调整手臂，避免身体持续悬空或保持俯卧撑姿势。恢复时先改变支撑姿态，再起身；车辆或实体障碍占用站立空间时，暂缓起身并保留躺倒状态，空间清空后才恢复站立碰撞。

行人会预测前进和倒退来车在短时间内是否逼近，侧移并逃开。预测有反应时限及视线限制：突然贴近仍能撞到；停车不会持续惊吓路人。普通行人仍可受到真实拳脚伤害与车辆撞击，不会变成免伤布景。

近战辅助朝向加入实体视线检查，跳过墙后的近目标，避免出招转向无法触及的人物。同一场景已用真实重击命中可见目标，墙后人物保持满血。

保留上一版环道四个平接坡道、实体栏杆、连续桥面、六条道路与广场/绿地/滨江的自由驾驶，以及 M 地图、原有连击、格挡、闪避、敌人主动攻击、破坏与存档。

倒地后测试中模型最低支撑边界距地面约 0.025 m，躯干中心约 0.293 m；手臂已从持续撑起身体改为放松落地。用真实车辆停在站立空间上方等待 150 个物理帧，人物保持倒地和关闭站立碰撞；车辆驶离后可恢复起身。来车避让测试中行人保持满血，车辆实际通过。

第22轮功能检查虽通过，但截图发现倒地像俯卧撑，随后修改并加强躯干高度检查，第23轮重拍。四张过程截图和初版结果保留在 iterations/round-22-v044-reactions；本目录四张 PNG 是第23轮最新实际运行画面。所有截图均来自 Godot，没有生成图、合成游戏内容或浏览器代替。使用受控人物位置、真实操作/物理接触和固定镜头截取；正常游玩采用跟随镜头及主动 AI。

## 界限与复现

这是程序化关节动画和包围边界地面贴合，未加入完整布娃娃、手脚 IK 或逐肢体物理接触；不宣称达到《如龙》成品动作质量。躲车预测只看短时行驶方向，不是完整交通仿真。车辆保持不翻飞的直立控制方式；没有新增刚体悬挂系统。无剧情任务或室内。

Godot 4.5.2。完整：--headless -- --test --test-world --test-polish；新增专项：--headless -- --test --test-polish-only。测试存档独立使用 toon-test-save.json。战斗停顿使用真实毫秒，不要用 --fixed-fps 加速完整战斗验收。

导出包复验使用 Linux release 模板 --main-pack 指向 Dolphin2.pck；原生图形专项使用 tools/capture.py --test --polish 配合 NATIVE_CAPTURE_PACK。导出日志与 ZIP/PE/PCK 容器检查不等于 Windows 实机测试。
