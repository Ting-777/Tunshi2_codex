# 0.4.1 东方明珠细化 / 2026-10-21

在 0.4.0 原生户外样板上仅细化地标及其公共入口，保持三条最高准则、都市漫画画风、原版豚师、无任务范围和现有基础玩法。所有 Sites 均未修改。

## 实际结果

Windows 导出的同一 PCK 由 Linux release 模板从不含源码的空目录加载，原生 OpenGL 行为检查 38 / 38 通过，退出码 0。覆盖走路、上下车、转向、近战、连击、AI、破坏、存档及 M 地图等原有项目；逐项见 export-native-v041.log。

新增塔座主入口坡道实际通行检查：通过正常 forward 输入从公共广场走上平台，没有使用跳跃、直接改高度或越过碰撞；最终 (-64.0, 0.390839, -72.90332)，保持地面支撑。结果见 runtime.log 的 PEARL_ACCESS_CHECK true。

独立导出包输出五张 1600×900 实际引擎 PNG：全塔、下球近景、上球近景、入口和原有滨江视角。截图采用固定相机；拍摄入口时已让角色经真实物理落地。当前捕获日志没有脚本或着色器错误。前两轮十张过程截图在 iterations。对话内两组压缩预览均小于 1 MB，图片解码和全部选项切换检查通过。

## 建模修改

三根分离的竖向主筒、三根斜撑和中段连桥；两颗主球、五颗位于三主筒之间的小球、三颗斜撑球形节点和顶部太空舱，共十一颗球体。上、下主球使用独立三角幕墙面板、细框、观光窗带、银色上下壳和舷窗。补全上球观光廊、天线桁架、检修平台和顶端杆体。

塔座改为分层基座、环形玻璃入口、屋顶肋条、三向遮棚、铺装广场、花池及三条实体坡道，碰撞跟随实际结构，公共区域可接近。高度约按 0.27 倍压缩，并按当前画风简化，不是测绘级复原或新开放室内。

本轮第一轮近景发现中段小球位置不合适及球壳颜色分区过于单一，第二轮已修正。全塔视角还暴露天空方位接缝，已改为水平周期采样，最终导出图中无该竖直断口。第三轮修正拍摄时角色悬空，先等待物理落地再拍摄。

结构参考上海市土木工程学会《上海东方明珠广播电视塔》：https://www.cnssce.org/52/201102/1152.html ，以及上海档案信息网的历史照片与资料：https://www.shda.gov.cn/dawh/csjy/202509/t20250919_75918.html 。参考照片仅用于观察，未作为游戏纹理或模型资产加入。
