## 修改

删除沿街前庭深色长线和额外分割网、街沿重复描边、无功能的地面字样及步道额外细缝。东方明珠广场删除装饰圆线和放射线；入口取消屋顶线条、密集玻璃格栅和门框重叠，采用完整屋面、较大的玻璃面、少量实体支撑及一个清楚的门框。塔柱删除装饰纵线和过多的环带。店面删除多余横向窗格与橱窗细条反光。幕墙网格增加像素过滤、降低对比度，远处细线逐渐淡出；铺装接缝减淡。

模型位置、碰撞体、原版豚师、车辆、战斗和存档逻辑未改；无新增任务或室内，所有 Sites 未改。
