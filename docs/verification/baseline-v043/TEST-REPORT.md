# 0.4.3 通行与路人互动验收 / 2026-10-21

本轮范围是原生 Godot 陆家嘴无任务样板。所有 Sites 未修改。三条最高准则保持原文：Gameplay 优先；视觉、操作、剧情一致；PS3 等级视觉方向。

## 修正内容

环道采用与可见桥面一致的连续环形碰撞；四条切向坡道与平台精确齐平，入口不再被完整外圈栏杆封住。内外栏杆及桥柱有匹配实体碰撞，国金底座与东侧桥面错开。桥面高 5.64 m，内外圈与上下坡的实际走路输入验收无须跳跃。

六条道路移除抬高的底板碰撞，人行道、广场、草地与滨江步道由连续地面支撑。路口停止绘制穿过另一条道路的路缘及标线。车辆自由横穿；保留真实建筑、墙、桥柱、栏杆和座椅等可见结构的碰撞。车辆顶住实体墙时不再继续积累虚假的速度值。

普通行人不再免伤，也能成为玩家拳脚命中的目标；有受击动作、退避与逃跑，附近路人会受惊。前进和倒车用车辆实际运动距离做形状扫掠，击退方向跟随行驶方向。倒地时取消站立胶囊对车的阻挡，保留地面与建筑碰撞；幸存者起身恢复身体碰撞。普通行人不掉敌人的现金奖励。

修复击退速度逐帧累积的问题。此次约 10.7 m/s 撞击中，NPC 从 z=82 滑退到约 83.677、倒车从 z=58 滑退到约 56.323；没有被抛出地图。更高车速的击退初速度上限为 12 m/s，持续衰减。

## 复现与身份

Godot 4.5.2。导入 project.godot 后，可用 --headless -- --test --test-world 运行完整实际物理输入测试；测试存档使用独立 toon-test-save.json。战斗的停顿效果依赖真实毫秒，因此不要用 --fixed-fps 加速完整战斗检查。

导出包复验：使用 Linux release 模板 --main-pack 指向 Dolphin2.pck；tools/capture.py --test --world --quick 配合 NATIVE_CAPTURE_PACK 运行原生复查。源码也附 tools/capture_impact.gd，可经 NATIVE_CAPTURE_SCRIPT 独立补拍，无须修改游戏逻辑。
