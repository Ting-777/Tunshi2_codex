# 2026-10-01 运货换车恢复

用户报告：夺取配送车后换乘街头白车，再返回配送车无法上车，T 重试仍绑定白车。

原因：配送车是任务车辆，换乘后被普通车辆检测排除；生产版旧检查点只保存位置，没有车辆身份。

修复：运货目标提供配送车专属上车交互；检查点新增车辆稳定键和 ID；运货重试明确选择配送车、清除速度并恢复耐久，兼容没有车辆身份的旧存档。B1 下车卸货流程保持原有任务进度。

验证：实际报告存档作为本地只读输入，测试 E 换车返回、再次换车、T 重试、刷新、报废重试、失败存档恢复及 B1 卸货/刷新。仓库测试使用独立构造的公开测试检查点，不包含用户存档。测试运行真实游戏交互与物理，DOM/WebGL 模拟。
