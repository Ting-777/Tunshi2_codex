## 连续拦截与真实保护目标

主路四波，西侧绕行共用前两波后再遇两波，总计四波。每波 3–4 人，分为追打田博的两名攻击者和牵制豚师的其余敌人。冲锋、掷瓶、守备与重型敌人穿插，重型敌人用于牵制豚师。田博被堵时停下，必须打退当前一拨才继续，跑到后面的导航点不能跳过战斗。

| 主路波次 | 路口 | 编组 |
| --- | --- | --- |
| 1 | 学院街出口 | 冲锋 / 拳手 / 守备 |
| 2 | 黄兴南路 | 拳手 / 掷瓶 / 守备 / 冲锋 |
| 3 | 步行街回口 | 拳手 / 冲锋 / 守备 / 重型 |
| 4 | 黄兴广场西口 | 拳手 / 冲锋 / 守备 / 掷瓶 |

西侧最后两波分别在西巷南口与黄兴广场西口，编组为拳手/掷瓶/守备/冲锋及冲锋/掷瓶/守备/重型。分支保留共用两波的 ID，HUD 不从零重新计数。

敌人从田博前后约 8–21 米处接近，生成点必须有足够碰撞净空、相同楼面、与他实际连通，彼此保持距离；窄巷先缩小侧向偏移，再尝试附近候选点。不能生成的组不会被静默算为完成，活着的组也不会被下一组替换。复用现有任务池，普通波次最多四人，仍保留全章八人任务池和八枚酒瓶上限。

追打他的敌人头顶有“目标：田博”，任务导航在围攻时指向田博，HUD 显示生命、波次和保护提示。近战保留蓄力、朝向、距离、遮挡和高度检查；冲锋在他的身前停到实际击打范围内。追打他的掷瓶手真正瞄准田博，保留落点预警、飞行与落地检查，不能由面板直接扣血。其他任务的酒瓶和固定记录机攻击规则保持。

田博为 140 生命，承受敌人基础伤害的 50%，有 1.2 秒受击保护。每拨退敌后一次性恢复 16，豚师恢复 6，并给出喘息提示；刷新不重复恢复。倒地先判定失败，不能靠同帧清场复活。初次进入广场战携带实际剩余生命；显式 T / 死亡重试恢复当前战斗的田博和敌人，避免带着零生命反复失败。玩家的奶冰永久防御不改变。
