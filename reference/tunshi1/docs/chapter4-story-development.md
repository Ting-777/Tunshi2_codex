## 最高准则与前章经验

1. Gameplay 优先。每段提供可执行、节奏不同的行动，剧情围绕行动展开；不用赚钱、随机获胜、重复消费或反复跑回设施作为门槛。
2. 视觉、操作、剧情一致。对白中的酒吧后门、KTV 后场、收货仓、货梯、商业通道、检修闸、接线箱和广告大屏，都有真实模型、开口、碰撞或状态变化。用实际移动、E/F/Q 输入和网格射线验证，不以改导航坐标掩盖几何问题。
3. PS3 等级视觉方向。延续既有建材、人物与夜间商圈风格，增加有结构和用途的室内空间；这只是方向，不声称已达到主机制作水平。保留 1080p 默认、60 FPS 上限、休眠和原有批处理，不用减少画质换取新剧情。

前几章留下的具体经验：战斗混合守备、冲锋、重型等角色，并给玩家可读蓄力、闪避、三拳破防和两段 Q 借物；路程用连接空间和分段检查点支撑，不让失败倒退整关；高度、脚下支撑、出口、角色层与存档恢复必须共同验证；使用有上限的角色池及战斗局部寻路，避免新增全城 A* 或无限增援。可读取这些仓库开发文档，但不能直接读取别的对话原文。

《如龙》相关参考用于街区设施、短局小游戏、连续城市行动和借物战斗的组织方式。保留豚师、长沙街区和本作的操作系统，不照搬任务、对白、商标或资产。前章已记录 SEGA 官方战斗资料：https://ryu-ga-gotoku.com/gaiden/asia_en/battle/ 。

## 剧情行情与永久系统

行情使用 `chapter.api.marketEvent`，每事件有稳定 ID，同时在剧情世界与市场侧去重，刷新、死亡、重试、迁移不会重复放大价格。

| 事件 ID | 触发节点 | 估值/当前报价影响 |
|---|---|---|
| `c4_night_settlement` | 牌馆结算凭证 | 饮品与娱乐项目上调 |
| `c4_guarantee_sync` | 比较江湾饮品、星潮文娱 | 关联担保使两家报价同步抬升 |
| `c4_records_cut` | 复制原始担保表 | 资料切断、饮品和商贸风险折价 |
| `c4_asset_exit` | 取得电子总账 | 娱乐、商贸、出行资产撤离折价 |
| `c4_network_exposed` | 户外楼宇屏幕实际显示签名材料 | 关联公司担保网络曝光，大幅折价；数码公司重估 |

倍率定义在 `dist/chapter4/story/missions.js`，后续剧情继续使用同一接口。面板每秒实时变价，全部订单依点击时的最新整数数量、分钱价格和钱包结算。1/4 仓、半仓、全仓继续有效。

牛奶绵绵冰仍为每份存档 ¥16、购买一次、+45 生命及永久减伤 25%；没有修改车辆耐久或敌人受到的伤害。主线不要求购买。天豚之靴必须先在 `c401-school` 与田博交谈后获得，持久标记为 `story.chapter4.world.boots`。取得前普通移动为 7.5 m/s，取得后第四章室外禁车路段为 12.75 m/s；不叠加，道路/停车区/室内/隧道/此前章节、蹲行/攻击/闪避/驾驶不变。地图试玩没有送鞋剧情，默认不提速。已有获得标记正常保留，旧剧情档缺少标记时仅按 `c401-school` 已完成的任务进度推断，未完成送鞋不提前授予。
